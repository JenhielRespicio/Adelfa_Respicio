# Project Title
## Hypotenuse Calculator

# Description
## The Hypotenuse Calculator is a simple program that calculates the hypotenuse of a right triangle based on two inputs.

# How to Run
## This program runs by asking for two user inputs, calculates them, and displays the results.

# Input Needed
## Inputs needed: 
- a
- b

# Sample Output
## Enter a length for side a: 6
## Enter a length for side b: 8
